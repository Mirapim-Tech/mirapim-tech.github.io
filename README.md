# Mirapim Tech

Static coming-soon website for https://mirapimtech.com.

HTML and CSS only: no JavaScript, dependencies, external fonts, analytics or forms.
The brand logo is supplied by the project owner and cropped for web display.

## Local preview

Run `python -m http.server 5188 --bind 127.0.0.1` and open http://127.0.0.1:5188/.

## Hosting

Repository: Mirapim-Tech/mirapimtech.github.io.
Intended hosting: GitHub Pages, with custom domain mirapimtech.com and enforced HTTPS.
GitHub Pages provisions the TLS certificate through Let's Encrypt once DNS is configured.
